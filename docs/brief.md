# 悟空 3D 角色 · 制作规格书（v0.1）

> 目标：**游戏实时角色 + 绑定动画 + 三维写实建模、水墨风格后处理**
> 参考：现有的 3/4 概念图（绿底、半写实水墨、低键伦勃朗光）
> 工程骨架：`wukong_base.blend`（单位米、正交三视图相机、分层集合）

---

## 1. 方向已经确定，由此推导出的硬性要求

| 决策 | 对资产的要求 |
|---|---|
| 游戏实时 | 必须 **低模 + PBR 贴图**，禁止靠高模/置换出效果；需 LOD |
| 需要绑定动画 | 必须 **T-pose 版本**用于绑骨；拓扑要满足变形（关节环线） |
| 三维写实 → 水墨化 | 模型和贴图保持**写实中性**，水墨效果在**引擎后处理**实现，不烘进贴图 |

**关键点：水墨是“后处理”，不是“建模风格”。** 所以贴图不要画成水墨笔触，否则引擎里再叠加描边/纸纹会脏；正确做法是“写实资产 + 后处理滤镜”。

## 4. 资产技术规格（游戏向）

### 4.1 网格

- 三角面（移动端）：LOD0 ≈ 15–18k，LOD1 ≈ 7–8k，LOD2 ≈ 3–4k；
- 单一角色拆成 **身体 / 白袍 / 裤 / 虎皮裙 / 靴 / 毛发 / 金箍 / 棍** 若干网格，共用一套骨架；
- 关节处环形布线（肩、肘、腕、髋、膝、踝），避免三角面出现在形变区；
- 对称部件用 Mirror 建模，最后 Apply；
- 尾巴单独一条骨骼链，网格独立或与身体合并均可。

### 4.2 UV / 贴图

- UV 无重叠（对称部件可镜像共用），统一 texel density；
- 贴图：BaseColor / Normal / ORM(AO+Roughness+Metallic)，PC 4K、移动 2K；
- **额外建议**：导出 `Curvature`、`Thickness` 两张辅助图——引擎后处理做墨线时非常有用。

### 4.3 骨骼

- UE5：对齐 Manny 命名（`pelvis/spine_01..03/clavicle_l/upperarm_l/...`）；
  Unity：Humanoid 映射 + 额外骨（尾巴、耳朵、飘带）；
- 手指 3 节 ×5，尾巴 6–8 节，下颌/眼球可选；
- 每顶点 ≤ 4 骨骼影响，权重归一化；肩、髋、裙摆是重点检查区。

### 4.4 表情与毛发

- 表情：ARKit 52 或至少 15 个关键形态键（游戏对话够用）；
- 毛发：**hair cards + alpha**（2–4 层）+ 头皮网格，不用曲线毛发；
- 布料：飘带可用骨骼或简模，别用高模布料模拟。

### 4.5 动画与导出

- 30/60 fps，循环动画首尾帧一致；
- 交付 `glTF 2.0 (.glb)` 为主、`FBX` 为辅，附骨骼命名表与动画列表；
- 导出前确认 forward/up 轴与引擎一致。

### 4.6 武器（金箍棒）

- **不合并进角色网格**：独立网格/场景，pivot 在握点（grip），方便换武器、换皮肤、做升级。
- 角色骨架加一根 `weapon_r` 挂点骨；Godot 里用 `BoneAttachment3D` 挂到右手，动画只驱动角色，武器跟随。
- 握持需要**握拳**姿势：绑定阶段把右手 bind pose 做成可握拳，或单独做握拳形态键。
- 金箍棒造型单独设计，不阻塞角色进度。

## 5. 水墨后处理方案

**原则**：资产写实，水墨在引擎里做，参数化可调。

1. 基础 PBR 正常打光（低键、侧逆光，伦勃朗式）；
2. 后处理链：
   - 边缘检测（深度 + 法线 + Curvature）→ 墨线；
   - 纸张纹理叠加（正片叠底/叠加）；
   - 降饱和 + 提对比 + 局部墨扩散（模糊后阈值）；
   - 可选 Kuwahara 滤镜做笔触感；
3. **Blender 里先做 look-dev**：合成器搭同样的链路，出对比图、锁参数，再 1:1 移植到 UE 后处理材质 / Unity URP Renderer Feature。
