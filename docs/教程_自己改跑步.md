# 自己改跑步动画 · 零基础操作手册

> 写给完全没碰过 Blender 的人。全程只用鼠标 + 几个快捷键，不写代码。
> 目标文件：`source/blend/wukong_rigged.blend`，里面只有一个动作 **Run**（18 帧 @ 24fps = 0.75 秒一个循环）。

---

## 0. 三十秒版本

1. 双击打开 `source\blend\wukong_rigged.blend`
2. 顶部工作区点 **脚本**，打开 `tools\blender\hand_edit_setup.py`，点 ▶ 运行（只跑一次）
3. 选中骨架 → 进 **姿态模式** → 点一根骨头 → 按 `R` 转 → 按 `I` 打关键帧
4. `Ctrl+S` 保存 → 命令行跑 `export_lod0.py` → Godot 里重新加载项目 → `F5`

下面把每一句拆开讲。

---

## 1. 先决定你要走哪条路

| 你想改的东西 | 走哪条路 | 一轮多久 |
|---|---|---|
| **整体感觉**：太趴了、太快/太碎、步幅太小、手摆得不够、上下蹦得太厉害 | **路线 B：改数字重烘焙**（第 6 节） | 3 分钟 |
| **某一帧的姿态**：触地那条腿伸到哪、手抬多高、头朝哪 | **路线 A：手动摆姿势**（第 3–5 节） | 第一次 20 分钟上手 |

**这两条路互斥。** 路线 B 的脚本会把整个 Run 动作删掉重建，你手动摆的东西全部消失；反过来，你手动改完就别再跑那个脚本。
不确定就走路线 A —— 那是你这次想做的事。

## 2. 动手前 60 秒准备

1. **备份**（`hand_edit_setup.py` 也会自动备份一份，但先手动复制一次最稳）：
   把 `source\blend\wukong_rigged.blend` 复制一份，改名 `wukong_rigged_我自己改之前.blend`，放同一个文件夹。

## 3. 路线 A · 第一次打开文件

### 3-1 认清三个区域（其它全都不用管）

- **中间最大那块**：3D 视图。看人、转骨头都在这里。
- **底部那条带数字的**：时间轴。拖帧、按空格播放。
- **右上角那棵树**：大纲视图（Outliner）。对象和骨骼的名字都在里面。

### 3-2 先跑一次准备脚本（**只跑这一次**）

现在这个 Run 动作是「烘焙」出来的：**18 帧里每一帧都有键**（每条通道 19 个）。
也就是说你在 f0 转一下骨头，f1 一点都不动 —— 播放起来就是「抽一帧」，没法改。

所以要先把键压成 9 个姿势帧（姿势帧上的数值一个都不改，只是扔掉中间那些键，让 Blender 自己补间）。这一步用脚本一次做完：

1. 点顶部工作区标签 **「脚本」（Scripting）**。
2. 中间那块是文本编辑器，点它的 **「打开」**。
3. 选 `D:\Workspace\games\WuKong\tools\blender\hand_edit_setup.py`。
4. 点右上角的 **▶「运行脚本」**。

它做了这些事：① 把整个文件备份到 `source\blend\backups\`；② 把键抽稀成 9 个姿势帧；③ 给**承重那条腿**在站姿期补回几个键（少了它们鞋底会陷进地面 3 厘米）；④ 把播放范围设成 0–17；⑤ 打开骨架穿透显示、保存文件、切进姿态模式停在 f0。

跑成功的标志：文件被保存过一次，骨架是橙色可选中的，时间轴范围变成 0–17。屏幕底部弹红字就是报错了，把红字发我。

> 抽稀之后：**9 个姿势帧和现在一模一样**（逐帧比对过，姿势矩阵误差 0），
> 只有两个姿势帧**之间**的补间略有不同 —— 脚最多差 5 毫米，手最多差 1.5 厘米，肉眼看不出。
> **就跑这一次**。以后你再跑它，你在中间帧手动加的关键帧会被删掉。

### 3-3 打开骨架 + 进姿态模式

1. 在大纲视图里点 **`Wukong_Rig`**（橙色/白色高亮）。**不要点 `Wukong_LOD0`**，那是皮。
2. 3D 视图左上角有个模式下拉框，写着「物体模式」，点开选 **「姿态模式」（Pose Mode）**。
   （快捷键：鼠标放在 3D 视图里按 `Ctrl+Tab` 来回切。）
3. 现在骨架是橙色的，但被衣服挡着看不见 —— 按 `Alt+Z` 打开「透视（X-Ray）」，骨头就透过模型显出来了。
   *（`hand_edit_setup.py` 已经帮你把「骨架在前面」打开了，可能不用按。）*

> 姿态模式里只能选中骨头，点身体是点不到皮的 —— 所以放心点。

### 3-4 把播放范围设成循环

时间轴左上角有两个数字框：**起始** / **结束**。应该是 `0` 和 `17`。
不是的话改成 0 和 17 —— 第 18 帧和第 0 帧一模一样，预览时跳过它，按空格（播放）时首尾才不卡。

按 **空格** 播放 / 再按一次暂停。**← →** 逐帧走。

### 3-5 认骨头（33 根，你只要管 24 根）

| 骨骼名 | 大白话 | 备注 |
|---|---|---|
| `pelvis` | 屁股 / 重心 | **最重要**。它的高低 = 身高起伏，它的角度 = 整个人趴不趴 |
| `spine_01` `spine_02` `chest` | 腰、背、胸 | 胸可以再单独压一点 |
| `neck` `head` | 脖子、头 | 转头、低头 |
| `clavicle_l/r` | 锁骨（肩膀） | 耸肩、含胸 |
| `upperarm_l/r` | 大臂 | 摆臂主要靠它 |
| `lowerarm_l/r` | 小臂 | 肘角 |
| `hand_l/r` | 手 | 没手指骨 |
| `thigh_l/r` | 大腿（髋关节） | 抬腿、前后跨 |
| `shin_l/r` | 小腿（膝关节） | 折膝 |
| `foot_l/r` | 脚 | 脚尖压 / 翘 |
| `toe_l/r` | 脚趾（脚掌前段） | 蹬地时折一下 |
| `tail_01`–`tail_04` | 尾巴四节 | |
| `root` | 整个角色的位移 | **别动** |
| `weapon_r` `grip_r` | 棍子挂点 | **别动** |
| `foot_ik_l/r` `knee_pole_l/r` | 旧的 IK 控制骨 | 已经关掉了，**别动** |

`_l` 是角色**自己的左边**（从正面看在你的右手边），`_r` 同理。

### 3-6 五个动作，会了就能改

**① 选骨头**
3D 视图里直接点骨头（先按过 `Alt+Z`）；或者在大纲视图里点名字，最保险。
打关键帧之前，确认**只有你要改的那根骨头是亮的**（`Alt+A` 全不选，再点它）—— 按 `I` 是给所有选中的骨头一起打帧。

**② 转它**
按 `R`，再按一次 **`X`** 或 **`Y`** 或 **`Z`** 锁定方向，然后移动鼠标，左键确认。

| 按 | 效果 | 用在哪 |
|---|---|---|
| `R` → `X` | **前后**转（低头、含胸、腿往前/后摆） | 90% 的修改都是这个 |
| `R` → `Y` | **左右倒**（身体歪） | 侧倾 |
| `R` → `Z` | **左右转**（转腰、转头、腿内八/外八） | 扭转 |
| 同一个键**再按一次** | 换成「绕骨头自己的轴」 | 细调手/脚朝向 |

- 想输精确角度：`R` → `X` → 直接敲 `8` → 回车 = 转 8 度。
- 反方向就是负号：敲 `-8`。
- 转错了：`Esc` 取消，或 `Ctrl+Z` 撤销。

**挪位置（只有 `pelvis` 需要）**
按 `G` 再按 `Z` = 上下挪，`G` 再按 `Y` = 前后挪，移动鼠标左键确认；之后同样按 `I` 打关键帧（这次选「位置」）。

**③ 打关键帧（把它记下来）**
摆好姿势后按 **`I`**，弹出菜单里选 **「旋转」（Rotation）**。
只转了就不用管位置；如果你还挪了 `pelvis` 的位置，再按一次 `I` 选「位置」。

> **不打帧 = 白改。** 不按 `I` 的话，你一拖时间轴或者一换帧，姿势立刻跳回原样 ——
> 「我明明改了怎么没变」十次有九次是这个。

> 关键：**在哪个帧上摆，就只影响那个帧。** 这个循环只有 9 个姿势帧：
> **f0 触地 / f2 压下 / f5 蹬离 / f7 腾空最高 / f9 换脚触地 / f11 压下 / f14 蹬离 / f16 腾空最高 / f18 = f0**
> 改动请落在这些帧上，中间的帧让 Blender 自己补。
>
> ⚠️ 一个例外：**正在承重的那条腿，在站姿期（左腿 f0–f5、右腿 f9–f14）每帧都有键**
> —— 那是脚本故意补的，不然鞋底会陷进地面。所以这几帧上改腿，改动只停在那一帧（会「抽一下」）。
> 这其实是对的：承重的腿一帧都不能乱动，动了就是滑步。

**④ 把这个姿势复制到别处**
`Ctrl+C` 复制姿态 → 拖到目标帧 → `Ctrl+V` 粘贴（只对当前选中的骨头生效）。

**⑤ 首尾和左右要同步**
循环动画的 f0 和 f18 必须完全相同，否则跑起来在接缝处会「抽一下」。改完 f0，记得把同样的改动在 f18 上再做一遍（或者 `Ctrl+C` / `Ctrl+V` 搬过去）。

左右两条腿是镜像关系：你在 f0 改了「身后那条腿」，f9（另一只脚触地）上对应的另一条腿也得改，方向相反。
省事做法：只选中你改过的那几根腿骨 → `Ctrl+C` → 到 f9 → `Ctrl+Shift+V`（粘贴翻转姿态）。
**注意：不要选着手臂一起镜像** —— 这个角色右手持棍，故意设计成右臂摆得比左臂小，镜像会把这点抹平。

### 3-7 第一次练习：三分钟改一个姿势

目标：让**触地那一帧**的后腿再张开一点。

1. 时间轴跳到 **f0**。
2. 大纲里点 **`thigh_r`**（左脚触地时，右腿在身后）。
3. `R` → `X` → 敲 `10` → 回车（往后 10 度）。
4. 按 `I` → 选 **「旋转」**。
5. 按空格播放：只有触地那两帧变了，其它帧不动 —— 这就是「改一个姿势」的感觉。
6. 想保留：照 3-6 ⑤ 同步 f18（同一条腿）和 f9（另一条腿，方向相反）。
7. 不满意：`Ctrl+Z` 撤销，或者直接把角度改成别的数字重来。

练完这一遍，你就掌握了全部操作；剩下的只是判断力。

### 3-8 怎么看改得对不对

1. 鼠标在 3D 视图里按 `Home`（全览），点视口**右上角坐标轴的 X 圆点** = 从侧面看（跑步主要看侧面）。
2. 逐帧 `←` `→`，重点盯 4 个姿势帧。
3. 判据（不用懂动画也能看）：
   - **脚**：踩地的那几帧，鞋底要贴着地平面（网格线），不能陷进去、也不能悬空。
   - **脚不许飘**：一只脚踩地的期间，它不能在地面上前后滑 —— 这条最容易在手动改的时候破坏。
   - **剪影**：眯眼看黑色轮廓，触地那一帧应该是「前腿伸直、后腿留在身后」的 **A 字**，不是两条腿都缩在身体下面。
   - **手**：一只在前一只在后。两只手都在胸前 = 像抱拳/拳击护手，不像跑。
4. 对照参考图：`docs\refs\sketch\run_cycle_sketch.png`（当初就是照它做的）。自己的帧和它逐张对着看，比凭感觉调快得多。
5. 数字体检（可选，命令行跑）：
   ```
   & "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --python "D:\Workspace\games\WuKong\tools\blender\check_run_action.py"
   ```
   会打印每一帧的 `minZ`（鞋底最低点）和脚掌角度。踩地帧的 `minZ` 应该在 `-0.007 ~ +0.003` 之间。

## 5. 常见「看着难受」→ 改哪根骨

| 症状 | 改哪根 | 怎么改 |
|---|---|---|
| 整个人像在鞠躬 / 趴着跑 | `pelvis`，其次 `spine_01` | 触地帧按 `R X` 往回转 5–8 度（负方向） |
| 后腿没张开、像小碎步 | `thigh_l/r` | 触地帧的后腿再往后转 10–15 度 |
| 膝盖抬不起来、像贴地滑 | `thigh` + `shin` | 在抬腿最高点（右腿约 **f4**、左腿约 **f13**）`thigh` 往前上转 15–20 度，`shin` 折 25–35 度 |
| 两只手都缩在胸前 | `upperarm_l/r` + `lowerarm_l/r` | 让一条臂明显向前、另一条明显向后；肘角别两个都一样 |
| 一蹦一蹦像跳 | `pelvis` 的位置 | 上下起伏的差太大：选它按 `G` → `Z` 往下挪一点，再按 `I` 打位置帧 |
| 脚在地上滑 | `foot` / `thigh` | 踩地的几帧里脚不能前后动，见 3-8 |
| 外八字明显 | `thigh`/`shin` 的 `R Z` | 往内收；鞋有 43% 权重在小腿，收一半就好，别硬掰脚 |
| 腿看起来短 | —— | 是蓝裙子遮到膝盖（已知问题），改它要动权重，别在动画里解决 |
| 头一直低着 | `neck` / `head` | `R X` 抬起来 |

改完满意 → 走第 4 节的导出三步。

## 7. 红线（碰了会白干）

1. **别跑 `build_run_action.py`** —— 前提是你走的是路线 A，它会重建整个 Run。
2. **别改骨骼的「旋转模式」**（现在是四元数 Quaternion）。改了以后老的曲线会读错，人会乱扭。
3. **别在物体模式里移动/缩放骨架或模型**（`Wukong_Rig` / `Wukong_LOD0`）。要动就动骨头。
4. **别碰** `root`、`foot_ik_l/r`、`knee_pole_l/r`、`weapon_r`、`grip_r`。
5. **别增删骨骼、别动权重**（权重绘制模式）。那是另一件事。
6. **别改帧率**（24），改了游戏里的速度就对不上。
7. Blender 撤销只有 32 步，改一大轮就 `Ctrl+S` 一次。

## 8. 改坏了怎么退回去

按这个顺序试：

1. Blender 里 `Ctrl+Z` 撤销。
2. 想整体丢掉没保存的改动：**文件 → 恢复（Revert）**，确认后回到上次保存的状态。
3. `source\blend\backups\` 里躺着 `hand_edit_setup.py` 自动存的完整副本，改个名字打开就能回。
4. 同目录下的 `wukong_rigged.blend1` 是 Blender 自动留的上一版（不想要它的时候别删）。

## 9. 文件里那些你别动的对象

- `Wukong_LOD0` / `LOD1` / `LOD2`：三档精度的皮。`LOD1` `LOD2` 的眼睛是闭着的（视口隐藏），保持这样。
