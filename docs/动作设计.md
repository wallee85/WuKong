# 悟空 · 动作与战斗设计（v0.1）

> 目标：从现在的「idle + 一个挥棒」扩展成一套**可玩的第三人称战斗动作集**：跑、三连击、招式、受击，并用手感参数把它调顺。
>
> 原则：**先把节奏和状态机定死，再谈动画精度**。节奏错了，动画再细腻也难玩。

---

## 1. 动作清单

| 动作 | 用途 | 循环 | 优先级 |
|---|---|---|---|
| `idle` | 待机 | 是 | 0 |
| `run` | 移动（不要 walk） | 是 | 1 |
| `attack_1` | 普攻第一段（右横扫） | 否 | 2 |
| `attack_2` | 普攻第二段（反手回扫） | 否 | 2 |
| `attack_3` | 普攻第三段（跃起下劈，终结） | 否 | 2 |
| `skill_spin` | 招式：原地旋棍（范围伤害） | 否 | 3 |
| `hit` | 受击硬直 | 否 | 4 |
| `death` | 死亡 | 否 | 5 |

暂不做：闪避、跳跃、格挡、处决。先把基础四件套（跑、三连、招式、受击）做扎实。

---

## 2. 状态机

```
        ┌──────────── 松开移动 ────────────┐
        ▼                                  │
     [ IDLE ] ──移动键──▶ [ RUN ] ──停止──▶┘
        │                   │
        │ 攻击键             │ 攻击键
        ▼                   ▼
   [ ATTACK 1 ] ──连击窗──▶ [ ATTACK 2 ] ──连击窗──▶ [ ATTACK 3 ]
        │                                                   │
        └──────────── 后摇结束 / 无输入 ────────────────────▶ IDLE
        │
        │ 招式键
        ▼
   [ SKILL_SPIN ] ──结束──▶ IDLE / RUN

   任意状态 ──受击──▶ [ HIT ] ──结束──▶ IDLE
```

**规则**

- `ATTACK` / `SKILL` / `HIT` 期间**锁移动**（或只允许很小的前冲位移）；
- `HIT` 优先级最高，可以打断攻击（但打断 `SKILL` 需要额外设定，见第 6 节）；
- 连击只在**连击窗口**内接受输入，窗口外按攻击键从 `attack_1` 重新开始；
- `SKILL` 有冷却（建议 6 秒），冷却中按键无效并给一个 UI 提示。

---

## 3. 连击规则

| 项 | 设定 |
|---|---|
| 输入缓冲 | 按键后 0.18 秒内有效（防止按早了丢输入） |
| 连击窗口 | 每段动作的 **55%–95%** 时长之间（例：0.45s 的 attack_1 → 0.25s–0.43s） |
| 段间过渡 | 直接切下一段，不做回 idle，允许 0.08s 的混合 |
| 终结段 | `attack_3` 后强制回 idle（不能无限连） |
| 重置 | 窗口内没按 → 回 idle，连击计数清零 |

|---|---|---|---|---|---|---|
| `attack_1` | 0.42s | 0.14s | 0.08s | 0.20s | 前冲 0.25m | 右横扫 |
| `attack_2` | 0.42s | 0.12s | 0.08s | 0.22s | 前冲 0.20m | 反手回扫 |
| `attack_3` | 0.62s | 0.20s | 0.10s | 0.32s | 前冲 0.45m | 跃起下劈 |
| `skill_spin` | 0.90s | 0.25s | 0.40s（多段） | 0.25s | 原地 | 范围伤害 |
| `hit` | 0.35s | — | — | 0.35s | 后退 0.15m | 硬直 |

**手感参数**（先给默认值，后面调）

- 命中停顿（hitstop）：0.06s，命中瞬间冻结双方；
- 摄像机轻震：命中时 0.15 强度、0.1s；
- 攻击时角色轻微前倾 5°；
- 连击每段伤害递增：10 / 12 / 18。

## 5. 操作映射

| 输入 | 行为 |
|---|---|
| `W A S D` | 移动（相机相对方向） |
| `Shift`（按住） | 跑步（默认就是跑，Shift 可做冲刺，暂不做） |
| `J` / 鼠标左键 | 普攻（连击） |
| `K` | 招式（旋棍） |
| — | 受击由敌人/碰撞触发 |
| `I` | 切换水墨（现有功能挪到 I，避免和招式冲突） |

## 6. 技术实现路线

我们现在的骨架是 AI 生成 + 自动权重：**手指是融合的拳头、没有表情骨**，所以动画只能靠身体和手臂。

分三层做：

1. **程序化驱动（先做）**
   在 `_physics_process` 里直接改骨骼姿态：idle 呼吸、run 摆腿摆臂、攻击用关键姿态插值。
   优点：迭代快、不用反复导出 40MB 的 GLB；缺点：动作偏“机械”。
   目标：把**节奏和判定**调到能玩。

2. **Blender 关键帧（后做）**
   在 Blender 里给 `run` 和 `attack_1..3` 手 K 关键帧（30fps，20–30 帧/段），导出成 glTF 动画。
   优点：动作自然；缺点：每改一次要重导出。

3. **AnimationTree 状态机（最后做）**
   动画资产齐了以后，把第 1 层的程序化逻辑换成 `AnimationTree` + `AnimationNodeStateMachine`，代码只负责发“进入某状态”的请求。

> 现在只有 idle + 一个攻击，所以第 1 层直接用代码状态机就够了；等动画资产多了再迁到 AnimationTree，接口不变。

---

## 7. 分步计划

| 步骤 | 交付 | 验收 |
|---|---|---|
| **1. 状态机骨架 + 跑** | `combat_controller.gd`：IDLE/RUN 切换、WASD 移动、相机跟随、跑步摆腿（程序化） | 按 WASD 能跑起来，镜头跟着，动作不穿模 |
| **2. 三连击** | attack_1/2/3 姿态 + 连击窗口 + 输入缓冲 + hitstop | 连点三下能打完三段，节奏顺、不吞输入 |
| **3. 招式** | `skill_spin` 旋棍 + 冷却 + 范围判定占位 | 按 K 出招，冷却期间按键无效 |
| **4. 受击** | `hit` 硬直 + 击退 + 优先级打断 | 受击能打断攻击，动作结束回 idle |
| **5. 精修** | Blender 重做 run/attack 关键帧，替换程序化版本 | 动作自然度提升，帧数据不变 |

**每一步都单独可玩、可回退**，不会出现“做了一半不能跑”的状态。

## 8. 风险与依赖

| 风险 | 影响 | 对策 |
|---|---|---|
| 骨骼局部轴向不直观 | 程序化旋转容易转错方向 | 先写一个“轴向校准”小工具，逐个骨头试转 30° 看方向 |
| 拳头没有手指 | 抓握、结印类动作做不了 | 招式避开手部细节，用棍势和身体表现 |
| 自动权重在肩/胯偏软 | 大幅动作会塌 | 攻击幅度先控制在 ±60°，必要时手工补权重 |
| 没有 walk | 低速移动会“滑步” | 只做跑，移动速度固定在 3.2 m/s，避免慢速滑步 |
| 无根运动数据 | 位移靠代码 | 攻击位移用曲线驱动，和动画节奏对齐 |

## 9. 跑步规范（协调 / 大跨度 / 舒展）

### 9.1 四个关键姿势，不用正弦

一个步态周期 = 左右各一次，拆成四个关键时刻插值：

| 相位 | 姿势 | 要点 |
|---|---|---|
| 0.00 | 左脚**触地** | 前腿几乎伸直、后腿蹬伸到最远；左臂后摆、右臂前摆 |
| 0.25 | **过渡**（重心最高） | 支撑腿直立、摆动腿屈膝抬到身前；身体最高 |
| 0.50 | 右脚触地 | 与 0.00 镜像 |
| 0.75 | 过渡 | 与 0.25 镜像 |

姿势之间用 **ease-in-out** 插值，触地前后各留 1 帧“硬”一点，避免整体像在水里。

### 9.2 协调（对侧原则）

- **左腿前 → 右臂前**，永不同手同脚；
- 肩与胯**反向扭转** 6–10°（胯随前腿转、肩随摆臂反向转）；
- 头部稳定，视线朝前，不要跟着躯干晃。

### 9.3 大跨度 + 舒展

| 参数 | 值 |
|---|---|
| 步幅 | 1.6–1.8 m |
| 步频 | 2.2–2.4 步/秒 |
| 移动速度 | ≈ 3.6–4.0 m/s |
| 大腿摆幅 | ±45°–55° |
| 前腿触地 | 膝盖接近伸直（伸展感来源） |
| 后腿蹬伸 | 髋部打开、脚尖离地 |
| 手臂摆幅 | 摆到肩线附近，肘部打开，不贴身 |
| 躯干 | 前倾 8–12°，胸口打开不驼背 |
| 尾巴 | 向后上扬、随步伐左右摆，做平衡 |

**“舒展”的关键是两端到位**：前腿伸直 + 后腿蹬直 + 手臂摆满，中间过程可以快，但两个端点必须撑开。

### 9.4 要避免的

- 同手同脚（最明显的“假”）；
- 膝盖永远弯着（显得蹲着跑）；
- 身体上下弹跳超过 5cm；
- 手臂贴着身体摆（幅度全被衣服吃掉）。

## 10. 范围伤害设计（所有攻击都是 AoE）

悟空的棍子长、招式大，**普攻也按范围伤害做**，不做单体点攻击。

### 10.1 判定形状

| 动作 | 判定 | 参数 |
|---|---|---|
| `attack_1` 右横扫 | 扇形 | 半径 2.0m、角度 120°，跟随角色朝向 |
| `attack_2` 反手回扫 | 扇形 | 半径 2.0m、角度 120°，反方向 |
| `attack_3` 跃起下劈 | 圆 + 直线 | 前方 2.4m 矩形走廊 + 落点 1.2m 圆 |
| `skill_spin` 旋棍 | 环形 | 半径 1.6m，360°，每 0.15s 一次判定 |
| `hit` 受击 | 单体 | 由攻击方判定，受击者只做反应 |

### 10.2 命中规则

- **每次攻击每个目标只吃一次伤害**：给每次挥击一个 `hit_id`，目标记录已吃过的 `hit_id`；
- 多段招式（旋棍）用 **tick** 区分，每 0.15s 换一个 `hit_id`，允许同一目标被多次命中；
- 判定帧只在“判定”窗口内生效（见第 4 节帧数据），窗口外碰到不掉血。

### 10.3 表现配套（很重要）

- 挥棍时加**棍身拖尾**（Trail 或粒子），让范围“看得见”；
- 下劈落点加**尘土/裂纹**贴花；
- 旋棍时脚下画一圈**淡淡的墨环**，提示范围；
- 命中时 hitstop + 相机轻震，范围伤害可以叠加轻微屏幕边缘暗角。

> 范围伤害的游戏意义：站位比瞄准重要。玩家要主动走进人堆里转棍，而不是站在原地戳。
