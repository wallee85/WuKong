## 0. 三轮反馈收敛出来的东西

| 轮次 | 反馈 | 真正的原因 |
|---|---|---|
| v15 | "一团糟" | 前倾 31° 趴着跑；站姿 21% 时另一条腿已蜷到屁股下；两只手都在身前 |
| v16 | "没怎么动"（其实是编辑器缓存，已用 `probe_run.tscn` 证明游戏里是新数据） | 变化没到用户眼前 |
| v17 | "四个都有问题"：步幅 / 后腿张开 / 膝盖 / 手臂 / 姿态 / 节奏 | **几何约束**：0.82 m 腿 + 4.2 m/s → 扫掠上限 0.77 m → 步频被顶到 ~190 |

**最关键的一条结论**（改变这个动画最有效的旋钮，按顺序）：

1. **速度**。步幅和步频不是独立的：`扫掠 = 速度 × 站姿时长`，扫掠又被腿长锁死。
   4.2 m/s 下不可能"步幅大且节奏慢"。降到 3.40 m/s 后，同样 0.765 m 扫掠给出
   160 步/分、1.275 m 步长 —— 这是这具身体"跑起来好看"的工作点。
2. **站姿占比**。它决定"接触那一刻另一条腿在哪儿"。低于 ~25% 就必然缩成一团。
3. **前倾角**。30° 以上从追尾机位看就是趴着跑；17° 才立得住。
4. 关节角度、肘角、摆动路径都是第 4 位的事。

## 1. 动作结构

- **四姿势 blocking**：f0 contact / f2 down / f5 pass(toe-off) / f7 up(腾空顶)，f9 镜像，f18 = f0。
- **间距**：骨盆高度逐帧给 18 个值，顶点驻留两帧；摆动腿关键帧非均匀（蹬离后慢、过顶后快）。
- **脚部**：站姿驱动**脚球**，球 −0.425 → +0.340 m 恒速 3.40 m/s；踝由球+pitch 反解。
  pitch 触地 +12° → 0 → 蹬离 +34°；摆动 +48°（脚尖朝下）→ −12°（朝上）→ +12°。
- **后腿**：蹬离后**继续向后走**到身后 0.46 m（sketch 的 "A"），到另一只脚触地时仍在
  身后 0.42 m / 高 0.30 m，之后才折起来。
- **膝盖**：最高点脚踝 z 0.390、膝前顶约 0.30 m，脚挂在膝下（不收到屁股）。
- **手臂**：左臂 ±52°，肘 **后摆 22°（近伸直甩到身后）↔ 前摆 98°（折在胸前）**；
  右手持棍 ±15°。手的前后行程 0.719 m、横向仅 0.013 m（2%，全在矢状面）。
- **鞋底标定**：`LIFT_V = [0, .010, .019, .021, .021]`，实测站姿 −7…+3 mm，
  摆动期 +2…+52 mm（脚尖不插地）。改 pitch / 站姿时长后**必须重跑** `calibrate_run_lift.py`。

  ANIM Run length=0.7500 loop=0 tracks=25 | SKELETON bones=33 | CHECK_OK

## 4. 已知问题

1. **靴子着地帧外八字 16.1°**（v15 曾做到 8.8°）。姿势变了之后靴子的 43% 小腿权重
   把脚带歪；调 `THIGH_TWIST/SHIN_TWIST` 只收回 ~1°。正解是按着地帧反解小腿世界 yaw
   或给靴子加校正骨，**别再只调 `FOOT_YAW`**。
2. **腿在侧视里偏短**：蓝裙遮到膝盖（v14 已提过 14 cm），再改要动权重。
3. 速度从 4.20 降到 3.40 是**为了步幅**；游戏手感若嫌慢，唯一同时保住步幅的交换是
   降站姿占比（换回高步频）。
4. 持棍在**左侧机位**会和头部投影重叠（3D 里在肩右后，不穿模），追尾机位正常。
5. idle 仍是 `main.gd` 程序化的；三连击/旋棍仍是程序化插值。

## 5. 已失败过的做法（别再重复）

| 做法 | 结果 |
|---|---|
| 程序化正弦摆腿 / 4 姿势+微调 | 像摆腿机器 / 像快走 |
| 所有通道共用一个 `u` | 整具骨架是一块刚体 |
| 靠 `pose_bone.matrix` 读姿态校验 | 后台读到旧值；必须新进程 `frame_set` 后读 evaluated |
| 让踝匀速后移 | 抬跟时脚球比踝快 → 脚尖滑冰；要驱动脚球 |
| 肘部负幅度（前摆张肘） | 拳头停在肩高，读作出拳 |
| 摆臂极值放 0.35/0.85 | 每个触地帧两手都在胸前，读作拳击护手 |
| 前倾 31° + 站姿 21% | 趴着跑 + 后腿蜷在身下 |
| **4.20 m/s + 想要大步幅慢节奏** | 几何上不成立；只能降速 |
| 只转脚骨纠外八字 | 靴子 43% 权重在小腿，只能纠一半 |
| 改完不重开编辑器 | 看到的是旧缓存，白改 |

**教训**：先算"脚球扫掠 = 速度 × 站姿时长 ≤ 腿能到的范围"，再谈姿势；
改完必须 check_run_action + 四个 diag + 剪影 + 游戏内逐帧 + 和参考草图对拍，
并且**确认编辑器加载的是新数据**（`probe_run.tscn`）。
